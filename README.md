# 🧿 PokéDairy — Pokédex & Battle Simulator

Welcome to **PokéDairy**, your all-in-one **Pokémon search and battle app**, powered by [PokeAPI](https://pokeapi.co)!  
Search your favorite Pokémon, view their stats, abilities, and types — or pit two Pokémon against each other in a stat-based battle!

## ✨ Features

🔍 **Search Mode**
- Autocomplete Pokémon names while typing.
- View detailed Pokémon info: image, types, abilities, and base stats.

⚔️ **Battle Mode**
- Enter names for Player 1 and Player 2.
- Real-time stat comparison to decide the winner.
- Dynamic UI with Framer Motion animations.

🎬 **Opening Screen**
- Eye-catching animated landing screen using Tailwind CSS + Framer Motion.

📱 **Responsive Design**
- Mobile-first interface for a smooth experience on all devices.
